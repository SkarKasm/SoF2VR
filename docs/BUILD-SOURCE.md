# Source for the showcase binaries

This is the source snapshot for the accompanying `2026.11.17-r1` runtime.
The generated calibration headers reflect the owner's final saved weapon,
hand and finger edits. The release manifest records their hashes and the
binary hashes. No compiler or authoring tools are needed to play the mod.

## Compile the runtime

Use the x86-hosted **llvm-mingw 20261006 MSVCRT toolchain**, with both the
i686 and x86_64 targets. Obtain it from the official llvm-mingw project:
https://github.com/mstorsjo/llvm-mingw/releases

In this `source` directory:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Runtime.ps1 -ToolchainBin "D:\Tools\llvm-mingw\bin"
```

This compiles the x86 proxy, x64 helper and mode launcher into `source/out`.
It does not install or launch them. It uses the accompanying generated
headers and x64 loader import library. Runtime proxy/helper source includes
all the source and interfaces needed for this build. Historical uncompiled
prototype sources are also retained, but are not part of the active runtime.
The owner’s saved hand edits are in `resources/hand_pose_overrides.json`.
The supplied PK3 is the reviewed converted asset output. It is independent
of recompiling the runtime and is not regenerated by this script.

`diagnostics` contains the first-party authoring/conversion Python sources,
without third-party Python packages, tests, caches or imported model archives.
Those optional authoring tools need the original game, licensed source assets
listed in CREDITS.md, and their own dependencies. Do not run historical build
installers expecting the original developer's folder layout. Use the supplied
Build-Runtime.ps1 to build the packaged runtime without asset regeneration.

## OpenXR loader

The bundled loader is Khronos OpenXR SDK release **1.1.63**, built as an x64
dynamic loader with the C++ runtime statically linked. Its exact binary and
import library are provided. Official corresponding upstream source:
https://github.com/KhronosGroup/OpenXR-SDK/tree/release-1.1.63

The original build used CMake/Ninja, `BUILD_TESTS=OFF`, `BUILD_API_LAYERS=OFF`,
`BUILD_CONFORMANCE_TESTS=OFF`, `BUILD_TESTING=OFF`, `DYNAMIC_LOADER=ON`,
`CMAKE_BUILD_TYPE=Release`, `CMAKE_CXX_FLAGS=-static`, and llvm-mingw's
`x86_64-w64-mingw32-clang/clang++/windres`. Build target: `openxr_loader`.
OpenXR headers and third-party loader notices are included under their
original licenses. Windows graphics/system libraries come with Windows.
